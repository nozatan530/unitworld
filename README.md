# 単位のつながりワールド

高校理科の単位を地図・錬成ラボ・クイズで探検しながら、単位どうしのつながりを確かめるWebアプリ

🔗 **公開URL**: https://unitworld.meetupsensei.com/

## 概要

高校理科（物理・化学・生物・地学）の87の単位を、7つの基本単位から組み立てられる順に並べたワールドマップで一望できます。
単位をかけ算・わり算して新しい単位をつくる「錬成ラボ」では、次元だけでなく係数（g と kg の違いなど）まで確かめます。
つくった組み合わせは「錬成ツリー図」に記録され、基本単位から何が生まれたかを枝分かれでたどれます。
日本語／英語の切り替えに対応しています。

姉妹版の [単位のつながり帳](https://unit.meetupsensei.com/) は、単位を調べて確かめるためのシンプルな一覧です。こちらは遊びながら探検する入口として使えます。

## 使い方

- **ワールドマップ**：87の単位を「組み立て順」（基本単位→1段目→2段目…）か「分野別」で一覧します。単位をタップすると、材料（青）と、その単位からつくれる単位（緑）が線と色で光ります。もう一度タップで詳細。cm・hPa・pH のような換算や目盛りの単位は、もとの単位の下に小さく添えています。分野のボタンでその分野だけ明るくでき、「つながり探索」で2つの単位を結ぶルートも表示できます
- **錬成ツリー図**：作りたい単位を選ぶと、基本単位からの作り方が木の形で表示されます。作れた単位は色つき、まだの単位は点線。点線の単位をタップすると、その単位の作り方に切り替わります
- **錬成ラボ**：目標の単位に向けて、材料の「× かける」「÷ わる」で組み立てます。「m：あと1回かける」のように、目標まで何が足りないかのヒントが出ます。目標を初めて達成すると演出が出ます
- **単位図鑑**：教科・種類・検索で絞り込み、単位の詳細（組み立て方、次元、同じ次元の単位、豆知識）を開けます
- **クイズ**：記号・SI基本単位での表し方・かけ算わり算の10問。教科で絞り込めます
- **接頭語・尺度**：k・m・μ などの接頭語と、pH・マグニチュードなど「単位ではない目盛り」の早見表
- 効果音は最初オフです（右上のスピーカーで切り替え）。端末で「視差効果を減らす」を有効にすると演出も控えめになります

## 技術

- React + TypeScript + Vite（Google AI Studio で作成したものを整理）
- Tailwind CSS、D3.js（錬成ツリー図）
- ワールドマップは HTML の並び＋選んだ単位の線だけを SVG で重ねる方式（拡大縮小なしで PC・タブレット・スマホに対応）
- GitHub Actions でビルドして GitHub Pages でホスティング
- カスタムドメイン: meetupsensei.com
