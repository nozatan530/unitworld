# 単位のつながりワールド

高校理科の単位を地図・錬成ラボ・クイズで探検しながら、単位どうしのつながりを確かめるWebアプリ

🔗 **公開URL**: https://unitworld.meetupsensei.com/

## 概要

高校理科（物理・化学・生物・地学）の87の単位を、分野ごとの「島」に並べたワールドマップで探検できます。
単位をかけ算・わり算して新しい単位をつくる「錬成ラボ」では、次元だけでなく係数（g と kg の違いなど）まで確かめます。
つくった組み合わせは「錬成ツリー図」に記録され、基本単位から何が生まれたかを枝分かれでたどれます。
日本語／英語の切り替えに対応しています。

姉妹版の [単位のつながり帳](https://unit.meetupsensei.com/) は、単位を調べて確かめるためのシンプルな一覧です。こちらは遊びながら探検する入口として使えます。

## 使い方

- **ワールドマップ**：単位をタップすると、材料（青い線）と、その単位からつくれる単位（緑の線）が光ります。点線は換算（Pa と hPa など）や対数の関係です。「つながり探索」で2つの単位を結ぶルートも表示できます
- **錬成ラボ**：「かける／わる」を選んで単位を入れると、SI基本単位での形と、できた単位が表示されます。お題（N・J・W・V など14題）を達成すると演出が出ます
- **錬成ツリー図**：錬成ラボで正しくつくれた組み合わせが記録されます。記録から材料をフラスコに戻すこともできます
- **単位図鑑**：教科・種類・検索で絞り込み、単位の詳細（組み立て方、次元、同じ次元の単位、豆知識）を開けます
- **クイズ**：記号・SI基本単位での表し方・かけ算わり算の10問。教科で絞り込めます
- **接頭語・尺度**：k・m・μ などの接頭語と、pH・マグニチュードなど「単位ではない目盛り」の早見表
- 効果音は最初オフです（右上のスピーカーで切り替え）。端末で「視差効果を減らす」を有効にすると演出も控えめになります
